# NewsPulse

GPU-accelerated news aggregation and NLP pipeline.

- Scrapes 100+ RSS feeds and web sources
- GPU sentiment analysis, summarization, NER (HuggingFace Transformers)
- Topic clustering via sentence-transformers + GPU KMeans
- Trend detection and historical comparison
- Streamlit dashboard for exploration

```bash
pip install -r requirements.txt
python pipeline.py
```
